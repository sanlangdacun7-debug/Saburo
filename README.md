# サブロー — あなた専用の株式投資AIエージェント

パスワードで守られた、あなただけが使える会話型AIエージェントです。
Anthropic の Claude（Claude Opus 5.5）を頭脳に使い、株式投資を専門にしています。
「/会議」で、役割ごとに独立したAI社員チーム（調査・運用・リスク・発注・CEO・監査役）を招集できます。

## 間違えを減らす仕組み

| AIのよくある間違え | サブローの対策 |
|---|---|
| 暗算ミス（金額・比率・数量） | 計算は `calculate`（安全な電卓）と `position_size`（単元・手数料込みの数量計算）をコードで実行 |
| 古い記憶の株価をそのまま書く | 株価・指数・為替・金利は `get_quote` / `get_price_history` で毎回取得し、時刻と出典を付ける |
| テクニカル指標の計算ミス | 移動平均・乖離・騰落率・最大下落率・ボラティリティはコードで計算して渡す |
| 出典のない数値・推測で埋める | Web検索に加えて一次情報を `web_fetch` で読む。確認できない値は「未確認」と書くルール |
| 一人の思い込み | 投資会議で担当ごとに独立して調べ、互いの報告を見せない（コードで強制） |
| 自分の間違いに気づかない | 監査役が「ブリーフと最終案だけ」を見て数値を再計算。差し戻しなら CEO が修正し再監査 |
| 未決定のことを決定済みにする | 決定台帳で「決定 / 未決定 / 取消」を管理し、全担当に渡す |
| 発注ミス | 発注はしない（草案のみ）。単元・指値と逆指値・口座区分・通貨の確認点を必ず出す |

## 投資会議（AI社員チーム）

チャットで `/会議 議題` と送ります（例: `/会議 トヨタ株を100万円以内で買うか検討したい`）。

1. ブリーフ作成（議題・決定事項・未決定事項・記憶）
2. ファンダメンタルズ担当・マクロ為替担当・テクニカル需給担当が**並行で独立に**調査
3. ポートフォリオ担当とリスク担当が**互いの報告を見ずに**検討
4. オーダーデスクが発注指示書の草案（数量は `position_size` で計算）
5. CEO が最終案を統合（選択肢と「オーナーが決める事項」）
6. 監査役が**作成過程を見ずに**独立検査 → 判定（承認 / 条件付き承認 / 差し戻し）
7. 承認でなければ CEO が修正し、監査役が再検査

監査役の報告は要約せず原文のまま表示されます。各担当の報告書全文は `data/meetings/` に保存されます。
数分かかり、通常の会話より API 料金も多くかかります（担当8〜10名分）。

## できること

- **会話**: 雑談・相談・調べもの・文章作成・事業計画づくりなど
- **記憶**: あなたの好み・目標・決めたことを自分で覚え、次の会話でも活かします
  （画面の「🧠 記憶」で一覧・削除できます）
- **Web検索**: 最新情報が必要なときは自分でネットを調べます
- **会話の保存**: 過去の会話は左のリストからいつでも再開できます
- **スマホ対応**: スマホのブラウザからもそのまま使えます

## はじめかた

### 1. API キーを用意する

[Anthropic Console](https://console.anthropic.com/) でアカウントを作り、API キーを発行します（従量課金）。

### 2. インストール

Python 3.10 以上が必要です。

```bash
git clone <このリポジトリ>
cd Saburo
python3 -m venv .venv
source .venv/bin/activate        # Windows は .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. 設定

```bash
cp .env.example .env
```

`.env` を開いて、次を書き換えます。

| 項目 | 内容 |
|---|---|
| `ANTHROPIC_API_KEY` | 手順1の API キー |
| `SABURO_PASSWORD` | ログイン用パスワード（必ず変更） |
| `SABURO_OWNER_NAME` | AI があなたを呼ぶ名前 |
| `SABURO_EFFORT` | 考える深さ。`low`（速い・安い）〜 `max`（賢い・遅い）。普段は `medium` |
| `SABURO_TEAM_EFFORT` | 投資会議の各担当の考える深さ（空なら `high`） |
| `SABURO_AUDIT_ROUNDS` | 監査の最大回数。`2` なら「監査→修正→再監査」（既定 2） |

### 4. 起動

**Web画面で使う**

```bash
python -m saburo.server
```

ブラウザで http://localhost:8000 を開き、パスワードでログインします。

**ターミナルで使う**

```bash
python -m saburo.cli          # 新しい会話
python -m saburo.cli --last   # 前回の続き
```

ターミナルでは `/memories`（記憶）、`/decisions`（決定台帳）、`/会議 議題` が使えます。
Web画面では左下の「📒 決定台帳」で台帳を確認できます。

## 株価データについて

株価・指数・為替は Yahoo Finance の公開チャートAPI（APIキー不要・非公式）から取得します。
遅延値の可能性があるため、**発注前は必ず証券会社の画面で価格を確認してください**。
銘柄コード例: `7203`（東証は4桁でOK）、`AAPL`、`^N225`、`^GSPC`、`JPY=X`、`^TNX`。

## テスト

AI もネットも使わずに、計算・データ処理・会議の段取り（情報の仕切り、監査の流れ）を確認します。

```bash
pip install pytest
python -m pytest tests
```

## 性格を変える

`persona.md` を編集すると、サブローの性格・話し方・役割を自由に変えられます。
`{owner}` はあなたの名前に置き換わります。

## データの保存場所

会話と記憶は `data/saburo.db`（SQLite）に保存されます。
このファイルはあなたのパソコンの中だけにあり、Git には含まれません。

## スマホや外出先から使うには

- 同じWi-Fi内のスマホから使う: `.env` に `SABURO_HOST=0.0.0.0` を追加して起動し、
  スマホで `http://<パソコンのIPアドレス>:8000` を開きます。
- 外出先から使う: クラウド（Render、Railway、Fly.io など）にデプロイし、必ず HTTPS で公開してください。
  パスワードは長く推測されにくいものにしてください。

## ファイル構成

```
saburo/
  agent.py      # 頭脳: 会話の受け付け、記憶・決定台帳ツール、/会議 の振り分け
  loop.py       # Claude API とのやりとりの共通ループ（サブローも各担当も使う）
  finance/
    calc.py     # 電卓・発注数量・テクニカル指標（コードで計算）
    market.py   # 株価データの取得（時刻と出典つき）
    tools.py    # 株式ツールの定義
    roles.py    # AI社員（各担当）の指示書
    team.py     # 投資会議の段取り（情報の仕切りと監査をコードで強制）
  store.py      # 会話・記憶・決定台帳の保存（SQLite）
  server.py     # Web サーバー（ログイン・チャット API）
  cli.py        # ターミナル版
  config.py     # 設定の読み込み
  static/index.html  # チャット画面
persona.md      # サブローの性格設定
```

## 次のステップ（AI会社に向けて）

サブローは「1人のAI社員」の土台です。ここから次のように広げられます。

- **役割ごとのエージェント**: `persona.md` を複製して、営業・経理・開発などの専門エージェントを作る
- **ツールの追加**: `agent.py` の `TOOLS` に、カレンダー・メール・社内データなどを操作する道具を足す
- **チーム化**: 社長エージェントが各専門エージェントに仕事を振る仕組みを作る
